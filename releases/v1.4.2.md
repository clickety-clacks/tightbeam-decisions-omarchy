# Tightbeam Decisions 1.4.2

## Fix

Restore a distinct completion attention signal for every decision window on
Scottland. The shared window host used Qt activation for finished replies;
Scottland could interpret that as focus from another window in the same app.
The host now identifies the finished window and marks that window for attention
through Scottland's per-window IPC. Its halo, or its rail widget's halo, remains
until you go to it. Hyprland continues to use Qt activation.

## Verification

All 17 bridge tests pass on Plumbus, including a two-window attention routing
test. JavaScript syntax and diff checks pass. The visual Scottland halo was not
exercised in a live decision window during this release.

## Upgrade

No new dependencies. Updating the plugin can reload open decision windows;
reopen them from the bar if needed.
