# Tightbeam Decisions 1.4.4

## Changes

- The first click in an unfocused decision window focuses it. A ruling click
  records only when the window was already focused at the start of that click.
  Wheel scrolling continues to work without focus.
- Ruled requests show a large, full-window outcome with the recorded ruling
  and a prominent Close button. Escape or Enter also closes it.
- Your prompts in the conversation are four points larger at the default font
  scale.

## Verification

QML and bridge checks were run on Plumbus. No tests were run on osanwe.

## Upgrade

Updating QML can reload and close open decision windows. Reopen them from the
bar if needed.
