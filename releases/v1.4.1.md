# Tightbeam Decisions 1.4.1

## Changes

- The Codex model picker reads the installed adapter's available models when
  Settings opens. It caches the list for one hour and uses the bundled catalog
  if the adapter cannot provide a list. New models such as Sol 6.1 appear when
  the installed Codex CLI offers them.
- Claude model labels use versioned display names from the adapter, so an
  alias such as `opus[1m]` can appear as "Opus 5.5 (1M)". Empty lookups are
  retried, and successful lookups refresh hourly.

## Verification

- All 16 bridge tests pass on Plumbus.
- With an isolated current Codex CLI on Plumbus, the picker discovered
  `gpt-6.1-sol`, saved it at medium effort, and completed a real prompt.
- Claude display-name parsing is covered by a focused bridge test. Claude Code
  is not signed in on Plumbus, so its live model list could not be probed there.

## Upgrade

No new dependencies. Updating the plugin may reload open decision windows;
reopen them from the bar if needed.
