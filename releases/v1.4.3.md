# Tightbeam Decisions 1.4.3

## Fix

Finish the per-window completion attention fix from 1.4.2. A window host that
survived a desktop restart could retain an obsolete Hyprland shim address and
fail to find any decision windows. Scottland now lists windows through its live
Wayfire socket, then sends completion attention to the exact window ID.
Presenting an existing decision window also uses that live lookup.

## Verification

All 18 bridge tests pass on Plumbus, including window lookup and two-window
attention routing. The visual halo was not exercised in a live decision window.

## Upgrade

No new dependencies. Updating QML can reload and close open decision windows;
reopen them from the bar if needed.
